# assets — 本地形象（不进 git）

把一张图片放进这个目录，悬浮球就会自动把它当作**默认形象**：

```
assets/
└─ mascot.png        ← 名字必须是 mascot，扩展名下列之一
```

支持的名字，按优先级从高到低：

| 文件 | 内容类型 |
|---|---|
| `mascot.svg` | `image/svg+xml` |
| `mascot.webp` | `image/webp` |
| `mascot.png` | `image/png` |
| `mascot.jpeg` / `mascot.jpg` | `image/jpeg` |
| `mascot.gif` | `image/gif` |

只认这几个固定名字，目录也固定在包内——路由不会读取任何调用方提供的路径。

## 为什么这样做

社区的「鲸鱼娘」形象属于二创角色，其素材以 **CC BY-NC-SA 4.0** 授权（署名 / 禁止商用 / 相同方式共享），
与本仓库的 MIT 不兼容。把素材放进这个目录、并让 `.gitignore` 忽略它，就能：

- 你自己本地用上任何形象；
- 素材**永远不会进入仓库历史**，clone 的人不会被许可问题波及；
- 想公开分发素材时，由你自己决定许可与署名，而不是被这个仓库替你决定。

## 生效方式

1. 把图片放进**已安装副本**的这个目录：

   ```
   <profile>/node_modules/dsh-client-ui-ball/assets/mascot.png
   ```

   或放进仓库里的 `packages/dsh-client-ui-ball/assets/`，再跑一次 `scripts/install.ps1 -Force`。

2. **刷新页面**。插件在加载时探测一次该路由，探测结果决定用本地图还是内置图。

3. 想确认是否生效：打开悬浮球的「悬浮球外观」面板，形象预览会显示本地图。
   想临时换回来：设置里的「形象」填一个值（URL / 表情），或点「恢复内置」清空。

没有任何本地素材时，路由返回 404，悬浮球使用内置的原创 Q 版鲸鱼形象。

## 也可以完全不用这个目录

设置面板里的**「选择图片」**会把图片压缩后存进 `$DSH_HOME/settings.yaml`，
不需要碰文件系统，也不需要重装。这个目录适合"想让默认形象就是它"的场景。
